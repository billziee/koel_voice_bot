v3 posture

  • Net new residency exposure in v3 = Deepgram (US) for the streaming STT path; it's opt-in per bot (stream_stt), and the India-hosted Sarvam batch path remains the default for Hindi/Hinglish.
  • O-4 (local embedder) is a partial mitigation — it removes the NVIDIA embedding round-trip entirely when enabled.
  • In-region inference (O-7) — SageMaker Whisper/Orpheus + Bedrock in ap-south-1 — remains the documented path to eliminate US egress; still legal-gated (see FUTURE_PROCEEDINGS.md). PII redaction before every US egress (SECURITY_V3.md) remains the interim control.
